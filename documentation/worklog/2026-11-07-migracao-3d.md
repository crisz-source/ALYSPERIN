# Migração do jogo para 3D em terceira pessoa

- **Data:** 2026-11-07
- **Pedido:** "quero que você reconstrua totalmente o jogo para 3D... todas as
  funcionalidades... história, design continuam os mesmos... 3D, terceira pessoa".
- **Versão 2D preservada:** etiqueta git `versao-2d-final` (último estado 2D completo).

## Decisões técnicas
| Decisão | Motivo |
|---|---|
| Uma base de código só; peças 2D trocadas pelas 3D com os **mesmos nomes de classe e interface** | HUD, inventário, missões, telas continuam encaixando sem duplicar |
| Escala: **1 m = 1 tile 2D (16 px)**; velocidades/distâncias convertidas (÷16) | Mesmo ritmo de jogo (esquiva ~3,5 m, espada 1,5 m) |
| Lógica de combate no plano do chão (X/Z); Y só para gravidade | Regras idênticas às da versão 2D |
| Mira = para onde a câmera olha (`PlayerInput.aim_direction`, lido da câmera) | Entrada continua separada da lógica (regra do co-op) |
| Câmera: yaw → pitch (ombro direito) → SpringArm → Camera | Terceira pessoa sem atravessar paredes; personagem não tapa o alvo |
| Mouse preso no jogo; solto quando `input_blocked`/morto; Esc solta, clique prende | Inventário, diálogo e morte precisam do mouse livre |
| Visual "pixel 3D": render 640×360 ampliado (configuração já existente) | Visual do protótipo que o proprietário aprovou |
| Dados de habilidade/itens continuam na escala antiga; projétil converte (÷16) | Não precisa refazer os .tres |

## Etapa 1 — base de combate 3D ✅
- Portados: `DamageInfo` (empurrão Vector3), `Hitbox`/`Hurtbox`/`Interactable` (Area3D),
  `FloatingText` (Label3D sempre visível), `PlayerCamera` (câmera 3D), `PlayerInput`
  (mira pela câmera), `Player`, `BasicEnemy`, `Projectile`, `ItemPickup`, `GameArea`,
  `test_arena`. Nova `HealthBar3D`.
- Gerador `build_3d_core.gd`: jogador, inimigo, projétil, item no chão, arena 3D
  (64×36 m, muros, pilares, tochas, neblina, lua).
- Cena principal temporária: arena 3D (a área de protótipo é a etapa 2).

### Problemas encontrados (etapa 1)
- Nenhum bug no jogo. 3 erros de teste: barra testada com vida acima do máximo; inimigo
  deixado de costas por um teste anterior (o 21 = 14×1,5 era o golpe pelas costas
  funcionando); mira resetada pela função de reposicionar antes do disparo. A sonda do
  projétil mostrou que ele detecta o muro e some no quadro 6.
- Visual: câmera centralizada fazia o personagem tapar o inimigo → câmera por cima do ombro.

### Testes (etapa 1)
